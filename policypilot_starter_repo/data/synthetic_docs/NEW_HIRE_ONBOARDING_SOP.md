## 1. Pre-start checklist
- Confirm signed offer letter.
- Create employee profile in HRIS.
- Request laptop and access badge.
- Assign manager buddy.

## 2. Day-one tasks
- Verify identity documents.
- Provide handbook and policy links.
- Review code of conduct.
- Enroll the employee in mandatory training.

## 3. First-week tasks
- Complete IT access provisioning.
- Complete security awareness training.
- Complete privacy training.
- Review team operating procedures.

## 4. Ownership
HR owns employee record creation. IT owns account provisioning. Hiring managers own role-specific setup.
